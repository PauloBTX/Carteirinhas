# Carteirinhas

Solução rápida e pontual, usada por um projeto social para gerar as carteirinhas dos estudantes que fazem matrícula.

## Aviso

Este repositório **não é um projeto de portfólio**. O código foi feito às pressas para resolver uma necessidade prática do projeto social e não segue, necessariamente, boas práticas de arquitetura, testes ou documentação. Não é um produto pronto nem uma referência de qualidade de código.

## O que faz

A aplicação em `ProjetoSocialCarteirinhas` permite carregar uma planilha com os dados dos estudantes matriculados, preencher o modelo de carteirinha e gerar os arquivos para impressão.

## Dados pessoais

Este repositório é público e **não contém dados de estudantes**. Planilhas, fotos, CPFs e demais informações pessoais nunca devem ser adicionados aqui.
